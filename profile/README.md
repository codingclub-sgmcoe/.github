## 👋 About Us

We're the **Coding Club** of the **Department of Computer Science & Engineering, SGMCOE**. A student-run community for anyone who wants to get better at writing code, from first-years opening a terminal for the first time to final-years shipping real projects.

Everything we build lives here: workshop material, contest solutions, club projects, and student contributions.

## 🎯 What We Do

| Activity | What it looks like |
|---|---|
| 🧠 **Competitive Programming** | Weekly practice sets, DSA sessions, and in-house contests |
| 🛠️ **Workshops** | Hands-on sessions on Git, Web Dev, Python, AI/ML, Linux and more |
| 🚀 **Hackathons** | Internal hackathons and team prep for national-level events |
| 🌱 **Open Source** | Guiding members through their first PRs and events like Hacktoberfest |
| 🤝 **Peer Mentoring** | Seniors helping juniors with projects, internships, and placements |
| 🎤 **Tech Talks** | Sessions with alumni and industry folks |

## 🙌 How to Join & Contribute

1. ⭐ **Follow** this organization to stay updated.
2. 🍴 **Fork** a repo, pick an issue labelled `good first issue`, and open a Pull Request.
3. 💬 **Talk to us.** Reach out to any club coordinator to get added as a member.
4. 📅 **Show up** to our workshops and contests. That's where the fun is!

```bash
git clone https://github.com/codingclub-sgmcoe/<repo-name>.git
git checkout -b my-feature
git commit -m "Add: my awesome feature"
git push origin my-feature
```
